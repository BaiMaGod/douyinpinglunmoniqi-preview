# 抖音评论模拟器 v8.2

这是一个纯前端单页工具，入口文件为 `index.html`，无需构建步骤。

## v8.2 更新：根据真人评论样本整改评论生成库

- 重写评论生成器，不再使用“求助信”式固定段落和文艺化句尾。采用真实评论常见的口语、短句、直接求助、多样称呼。
- 支持“我妈/妈妈/俺妈”“我爸/爸爸”“我爷爷/爷爷”等自然称呼；根据照片的已识别人物关系生成，不改变原有文件夹识别逻辑。
- 评论长度更接近真实留言，多数为一两句话，标点可以省略，表达先后顺序有变化。
- 约 23% 的新生成评论会自然带出去世原因，去世时间、儿时年龄只在部分评论出现；不再每条都添加。
- 表情数量从固定6个改为随机0～3个左右，默认“最多追加表情数”为3；仍然支持用户自行调整上限。
- 首次加载新版时，自动重配“未固定”中未手动编辑的评论；手动编辑过的文案与“已做视频”记录不变。
- 500条不同文件/关系的本地生成逻辑测试：500条唯一，平均约27字符，原因出现率约24%，不再包含旧文艺模板典型用语。

**重要：** 这些评论为模拟工具生成的虚构示例，不代表截图中的真实用户发表过相同内容。随机生成的去世时间、年龄、原因也仅为可编辑的模拟细节，请在使用前逐条核对，不要把虚构经历当成事实传播。

## v8.1 更新

- 已完成卡片的状态名称由“已固定”调整为“已做视频”。
- “已做视频”列表增加评论内容编辑框，支持插入抖音表情并保存修改。
- 保存修改后重新生成高清 PNG，并同步更新浏览器 IndexedDB 中的成品记录。
- 新完成的卡片同时保存原始照片 Blob；旧版已保存卡片可从原 PNG 中恢复照片区域，支持继续编辑评论。

## v8.0 更新

- 内置接入 436 款抖音 Android 表情资源目录（其中 214 款默认可见），支持搜索和手动插入表情。
- 自动生成的哭泣、祈祷、心碎等常用表情使用抖音表情图片，不再以自绘 SVG 作为最终显示素材。
- 表情图片按需下载并缓存到浏览器 IndexedDB；评论预览与高清 PNG 导出均使用缓存的原图。
- 保留导入本机 `small_emoji_res` 文件夹的功能，供在线资源不可用时补充或替换。

- 全局头像分配队列，统一管理固定卡片、普通卡片、手动换头像和批量分配。
- 头像分配同时检查素材 ID、图片 SHA-256 和视觉 dHash，拦截相同或高度相似图片。
- 中国相关真人头像可通过 Pexels API 扩充，目标为 1000 款；只登记 API 实际返回的不同照片，不用重复素材凑数。
- 去世原因以约23%的概率自然加入新生成评论，具体生成算法以v8.2为准。
- 本地 IndexedDB 保存头像清单、缓存图片、表情资源和卡片数据。

## 本地运行

直接用现代浏览器打开 `index.html` 即可使用基本功能。若浏览器对本地文件的跨域请求有限制，请通过本地 HTTP 静态服务器运行，再使用 Pexels API 功能。

## 头像扩充

1. 在 [Pexels API](https://www.pexels.com/api/) 申请 API Key。
2. 打开头像库面板，粘贴 API Key。
3. 点击“获取1000款中国相关真人头像”。

Pexels 搜索结果按关键词检索，不代表平台认证了人物国籍或族裔，导入后需要人工筛选。照片由 Pexels 提供，照片和摄影师来源链接保留在素材记录中。请遵守 [Pexels License](https://www.pexels.com/license/)；本仓库不打包再分发原始照片。

## 抖音表情库

模拟器内置连接公开的 [hnlyzxf/douyin-emoji 表情资源库](https://github.com/hnlyzxf/douyin-emoji)，读取其中的 `info.json` 和 `static/` 图片。该资源库记录 436 款表情，其中 214 款标记为默认可见。表情图片按需从 jsDelivr / GitHub Raw 加载，并缓存到当前浏览器的 IndexedDB；卡片预览和 PNG 导出使用缓存的图片。

如果在线资源无法访问，也可以从你自己的抖音 Android 应用数据目录准备 `small_emoji_res` 文件夹，包含 `info.json` 和对应图片，再通过“补充本地表情素材”导入。

表情资源来自第三方公开整理的抖音 Android 资源目录；本项目不将原始图片复制进代码仓库。资源库说明其图片版权归抖音及相关权利方。

## 数据与隐私

- Pexels API Key 仅保留在当前页面内存，不写入 IndexedDB。
- 本地卡片、头像缓存和导入表情保存在当前浏览器 IndexedDB。
- 清理站点数据或更换浏览器/设备后，本地数据不会自动同步。
