# 抖音评论模拟器 v7.0

这是一个纯前端单页工具，入口文件为 `index.html`，无需构建步骤。

## v7.0 更新

- 全局头像分配队列，统一管理固定卡片、普通卡片、手动换头像和批量分配。
- 头像分配同时检查素材 ID、图片 SHA-256 和视觉 dHash，拦截相同或高度相似图片。
- 中国相关真人头像可通过 Pexels API 扩充，目标为 1000 款；只登记 API 实际返回的不同照片，不用重复素材凑数。
- 支持导入用户本地提供的抖音 `small_emoji_res` 文件夹，读取 `info.json` 并匹配表情图片。
- 新生成评论以约 28% 的概率随机加入去世原因；不是每条都添加。
- 本地 IndexedDB 保存头像清单、缓存图片、表情资源和卡片数据。

## 本地运行

直接用现代浏览器打开 `index.html` 即可使用基本功能。若浏览器对本地文件的跨域请求有限制，请通过本地 HTTP 静态服务器运行，再使用 Pexels API 功能。

## 头像扩充

1. 在 [Pexels API](https://www.pexels.com/api/) 申请 API Key。
2. 打开头像库面板，粘贴 API Key。
3. 点击“获取1000款中国相关真人头像”。

Pexels 搜索结果按关键词检索，不代表平台认证了人物国籍或族裔，导入后需要人工筛选。照片由 Pexels 提供，照片和摄影师来源链接保留在素材记录中。请遵守 [Pexels License](https://www.pexels.com/license/)；本仓库不打包再分发原始照片。

## 导入抖音表情

从你有权使用的抖音 Android 应用资源中准备 `small_emoji_res` 文件夹，包含 `info.json` 和对应图片。通过头像库中的“导入 small_emoji_res 文件夹”导入。

本仓库不附带抖音官方表情图片。表情素材及相关数据的版权归抖音及相关权利方，商业用途请先确认授权。

## 数据与隐私

- Pexels API Key 仅保留在当前页面内存，不写入 IndexedDB。
- 本地卡片、头像缓存和导入表情保存在当前浏览器 IndexedDB。
- 清理站点数据或更换浏览器/设备后，本地数据不会自动同步。
